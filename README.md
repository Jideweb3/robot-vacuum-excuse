Entry for make.fun's "The Robot Vacuum's Funniest Excuse" bounty — a Python program that writes one line, the funniest excuse a robot vacuum gives for missing a spot, to $MAKEFUN_OUTPUT_DIR/entry.txt. The line: "I ran over it three times. It is still there. At this point we are roommates."

## Run it

```sh
python3 main.py
```
